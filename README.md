# Social Media Usage Analysis

## Project Overview
Developed an interactive Power BI dashboard to analyze social media usage patterns, user engagement, demographics, and activity trends. The dashboard provides meaningful insights using visualizations and KPIs.

## Technologies Used
- Power BI
- DAX
- Excel
- Data Visualization

## Features
- KPI Cards
- Interactive Charts
- Slicers and Filters
- Demographic Analysis
- User Engagement Analysis
