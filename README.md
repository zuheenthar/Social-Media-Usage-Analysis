# Social Media Usage Analysis

## Project Overview
An interactive Power BI dashboard that analyzes social media usage patterns across users, uncovering engagement trends, demographic distributions, and platform activity insights. The dashboard transforms raw usage data into clear, actionable visualizations to support data-driven decision-making for marketing and product strategy.

## Objective
To understand how different user segments engage with social media — identifying peak activity periods, demographic-based usage patterns, and engagement drivers — through an intuitive, interactive reporting interface.

## Technologies Used
- **Power BI** — dashboard design and interactive reporting
- **DAX (Data Analysis Expressions)** — custom calculated metrics and KPIs
- **Excel** — data cleaning and preprocessing
- **Data Visualization** — charts, cards, and cross-filtering visuals

## Key Features
- 📊 **KPI Cards** — at-a-glance summary metrics (total users, avg. engagement, etc.)
- 📈 **Interactive Charts** — visual breakdown of usage trends over time
- 🎛️ **Slicers & Filters** — dynamic filtering by platform, demographic, or time period
- 👥 **Demographic Analysis** — usage patterns segmented by age, gender, and location
- 🔥 **User Engagement Analysis** — likes, comments, shares, and activity frequency trends

## Insights & Impact
The dashboard enables quick identification of high-engagement user segments and peak usage windows, helping stakeholders make informed decisions on content scheduling and audience targeting.
